# MoleculeEvolverAnalysis 测试方案

## 1. 测试目标

为 [MoleculeEvolverAnalysis](file:///home/rhj/projects/mol_opt/mol-ofo/mol_evo/core/evolver.py#L25-L341) 类构建系统化、全面的测试方案，确保其能够正确处理各种分子结构和化学特性。

## 2. 测试策略

### 2.1 功能测试

按照分子类型和化学特性分类进行测试：

1. **基础链状分子**

   - 简单烷烃、烯烃、炔烃
   - 不同长度的碳链

2. **环状分子**

   - 单环化合物（3-8 元环）
   - 多环化合物（螺环、桥环、稠环）
   - 芳香环和脂肪环

3. **含杂原子分子**

   - 含氧、氮、硫、磷等杂原子
   - 杂环化合物

4. **多重键系统**

   - 双键、三键
   - 共轭体系

5. **立体化学**

   - 手性中心
   - 顺反异构

6. **复杂分子**
   - 生物分子（糖类、氨基酸等）
   - 药物分子片段

### 2.2 边界条件测试

1. **极简分子**

   - 单原子分子
   - 双原子分子

2. **复杂分子**

   - 大分子体系
   - 高度支化的分子

3. **特殊情况**
   - 无效 SMILES 输入
   - 不常见的化学结构

### 2.3 输出验证

1. **路径格式验证**

   - 字符串格式路径
   - 字典格式路径

2. **路径内容验证**
   - 起始原子选择正确性
   - 骨架构建正确性
   - 成环操作检测
   - 多重键识别
   - 立体化学信息

根据不同维度生成测试集：
