# 关于目标属性标准化的讨论总结

## 背景
在训练分子编辑模型时，我们对目标属性（如 `mu_change`）进行了标准化处理，即使在数据已经是百分比变化形式 `(to_smile - from_smile) / from_smile` 的情况下。

## 标准化的原因

### 1. 分布不确定性和一致性
即使使用百分比变化形式的数据，其分布可能仍然不确定。标准化可以确保数据分布的一致性，使模型训练更加稳定。

### 2. 模型训练优化
标准化后的数据通常具有更好的数值属性，有助于梯度下降算法更快收敛，避免因数值范围差异过大导致的训练不稳定。

### 3. 损失函数一致性
在代码中使用的是 L1 Loss (MAE) 作为损失函数，标准化后的数据可以使损失值保持在合理范围内，便于模型学习。

## 标准化的好处

### 1. 加速模型收敛
标准化使不同特征具有相似的尺度，这有助于梯度下降算法更快地找到最优解，显著减少训练时间。

### 2. 提高模型稳定性
当输入数据具有不同的量级时，模型可能会变得不稳定，梯度可能出现爆炸或消失。标准化可以缓解这些问题，提高训练过程的稳定性。

### 3. 改善数值计算精度
对于许多数值计算算法，当输入数据在相似范围内时，计算精度更高，避免了由于数值过大或过小导致的计算误差。

### 4. 使特征权重具有可比性
标准化后，不同特征的权重可以直接比较，更容易理解模型的决策过程和特征重要性。

### 5. 避免某些特征主导模型训练
在未标准化的数据中，数值范围较大的特征可能会主导模型训练过程，而标准化确保每个特征对模型训练的贡献更加均衡。

### 6. 有助于正则化效果
当使用正则化技术（如L1、L2正则化）时，标准化确保正则化项对所有特征产生相似的影响，避免某些特征因数值范围大而受到过度惩罚。
