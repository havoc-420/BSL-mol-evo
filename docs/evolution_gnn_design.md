# 基于分子进化的图神经网络设计

## 概述

本文档描述了如何构建一个基于分子进化思想的图神经网络(GNN)，其中：
- 节点代表完整的SMILES分子
- 边表示分子间的进化关系
- 边特征包含 `{pos, atom, op操作, 属性变化}` 四维信息

## 核心概念

### 节点表示
每个节点代表一个完整的SMILES分子（而非分子中的原子），节点特征可以包括：
- 分子的全局属性（如偶极矩、极化率、HOMO/LUMO能级等）
- 分子指纹或图表示
- 通过 `MoleculeEvolver` 生成的进化路径表示

### 边表示
边表示分子间的进化关系或相似性，边特征包含以下四个维度：

1. **pos（位置）**: 分子在进化路径中的位置/顺序
2. **atom（原子）**: 涉及转化的原子类型
3. **op操作（操作）**: 分子间转化的操作类型
4. **属性变化**: 分子属性的差异值

### 进化操作类型
基于 `mol_evo` 项目的实现，分子进化操作包括：
- 添加原子（Add atom）
- 添加片段/附件（Add fragment）
- 形成双键/三键（Form double/triple bond）
- 成环（Form ring）
- 指定手性（Specify chirality）

## 实现步骤

### 1. 数据准备
使用 `filter_evolution_step.py` 脚本从QM9数据集中筛选出一步进化关系对：

```bash
cd mol_evo/dataset
python filter_evolution_step.py
```

该脚本会：
- 加载指定原子数的QM9分子数据
- 计算分子间的结构相似性
- 识别编辑距离较小的分子对（一步进化关系）
- 提取边特征信息

### 2. 构建图结构
基于筛选结果构建图结构：
- 每个唯一的SMILES分子作为一个节点
- 每个进化关系对作为一条边
- 边特征按照 `{pos, atom, op操作, 属性变化}` 格式组织

### 3. 应用GNN模型
在构建好的图上应用图神经网络，如：
- NNConv：利用边网络将边特征映射为权重矩阵
- GAT-Edge：在注意力机制中整合边特征
- 标准GAT：作为基线模型

## 边特征详细说明

### pos（位置）
表示分子在进化序列中的位置信息，可以是：
- 分子的原子数（如11、12等）
- 在特定进化路径中的顺序编号

### atom（原子变化）
涉及的原子类型变化，包括：
- 新增的原子类型（如C、N、O等）
- 原子数量的变化

### op操作（操作类型）
分子间转化的操作类型：
- 添加原子
- 形成化学键（单键、双键、三键）
- 成环反应
- 添加立体化学信息

### 属性变化
分子属性的数值变化：
- 分子量差异
- 环数变化
- 原子数差异
- 其他量子化学属性差异

## 示例

考虑从乙烷(C2H6)到丙烷(C3H8)的进化：
- pos: 2（起始分子有2个碳原子）
- atom: ["C"]（添加了一个碳原子）
- op操作: "添加原子"
- 属性变化: {"molecular_weight_diff": 14.01, "atom_count_diff": 1}

## 应用场景

1. **分子性质预测**：利用邻居分子的信息改进预测
2. **分子生成**：学习分子进化规律指导新分子设计
3. **药物发现**：识别具有相似进化路径的活性化合物
4. **化学反应预测**：基于进化路径相似性预测反应可能性
