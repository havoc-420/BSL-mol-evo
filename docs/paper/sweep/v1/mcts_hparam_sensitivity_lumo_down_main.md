# OFO-guided MCTS 超参数敏感性（正文短版，LUMO(D)）

## 1. 使用定位

本稿用于论文正文中的 `Hyperparameter sensitivity` 小节，目标不是完整复述全部 sweep 结果，而是用**最少篇幅**支撑三条核心论点：

1. 搜索预算增加能够稳定提升性质优化幅度，但收益存在边际递减；
2. 探索系数直接控制性能与多样性之间的 trade-off；
3. 在 `OFO` 先验排序存在的前提下，有限分支宽度已经足以支撑有效搜索。

当前结论均基于 `LUMO` 下降任务，因而更适合作为**正文中的代表性证据**；更完整的结果表与细粒度分析建议放入附录。

## 2. 正文可保留的核心证据

| 维度 | 关键结果 | 论文层面的解释 |
| --- | --- | --- |
| `num_simulations` | 从 `100` 增至 `1600` 时，`average_improvement` 由 `-3.4154` 提升到 `-3.8891`，但 `IntDiv` 由 `0.4707` 降至 `0.3942` | 更高预算可持续释放搜索收益，但会带来多样性收缩，且收益呈递减趋势 |
| `exploration_weight` | 从 `0.5` 增至 `3.0` 时，`average_improvement` 由 `-3.4008` 提升到 `-4.1264`，成功率由 `89.88%` 升至 `93.28%`，同时 `IntDiv` 由 `0.4416` 降至 `0.2976` | 更强探索有利于跨越局部最优，但会明显压缩多样性并增大结构偏移 |
| `max_branching` | `10` 取得最高成功率 (`94.10%`) 与最高 `QED` (`0.3959`)，`5` 取得最强平均改善 (`-4.0772`)；而 `20/30` 并未继续提升性能 | `OFO` 的候选排序已足以支撑有限宽度搜索，过宽展开反而稀释预算 |

## 3. 可直接写入正文的短版段落

为评估 `OFO-guided MCTS` 对搜索侧超参数的敏感性，我们在 `LUMO` 下降任务上分别考察了搜索预算、探索系数与分支宽度的影响。结果表明，该方法并不依赖某一组偶然参数，而是在较宽参数范围内保持稳定有效。首先，随着 `num_simulations` 从 `100` 提升到 `1600`，平均改善值由 `-3.4154` 提升至 `-3.8891`，说明更高预算能够持续释放 `OFO` 提供的局部响应信号；但与此同时，`IntDiv` 从 `0.4707` 下降到 `0.3942`，表明性能提升伴随着多样性收缩。其次，增大 `exploration_weight` 能够进一步提升改善值与成功率，例如从 `0.5` 到 `3.0` 时，平均改善值由 `-3.4008` 提升至 `-4.1264`，成功率由 `89.88%` 提升至 `93.28%`，但更强探索也带来了更低的 `IntDiv` 与 `Morgan` 相似度，说明探索—利用平衡直接决定了性能与结构保持之间的 trade-off。最后，分支宽度实验显示，较大的 `max_branching` 并未带来更强性能，`5` 与 `10` 反而优于 `20` 与 `30`，支持了 `OFO` 候选排序足以支撑有限宽度搜索的判断。总体而言，这些结果说明 `OFO` 先验与 `MCTS` 搜索之间形成了稳定互补：更高预算与适度增强的探索能够提高性质改善，而高质量候选排序则使有限宽度搜索成为可能。

## 4. 正文中的推荐写法

如果正文只能保留一组简洁结论，建议写成：

- `num_simulations`：说明**预算增加有效，但收益递减**；
- `exploration_weight`：说明**探索增强提升性能，但牺牲多样性**；
- `max_branching`：说明**有限宽度已足够，过宽展开并无必要**。

`max_depth` 与 `pruning_patience` 建议移至附录，用于补充说明更深路径的收益饱和趋势，以及剪枝强度对结果的次级影响。

## 5. 正文推荐配置表述

若需要在正文中给出一组“平衡型默认配置”，可以写为：

- `num_simulations = 800`
- `exploration_weight = 2.0`
- `max_branching = 10`
- `max_depth = 10`
- `pruning_patience = 3`

这一配置兼顾了改善幅度、成功率、结果质量与搜索成本，更适合作为论文叙事中的默认设定；但若后续在 `LUMO(U)` 与 `HOMO(D)` 上得到同趋势结果，再将其上升为全局默认配置会更稳妥。
