# MCTS 消融绘图计划

## 1. 目标

这组图的目标不是罗列所有原始字段，而是**直接支撑正文里的三条核心说法**：

1. `leaf value` 对最终优化质量最关键；
2. 去掉 `leaf value` 会带来数量级更高的搜索成本。

## 2. 采用的图形设计

本次先做 **1 张三联图总览**，兼顾主文可读性和附录可复用性：

- **Panel A — Pilot truth improvement**
  - 数据源：`20260413_1536_pilot_mcts/true_eval_summary_aggregated.tsv`
  - 展示：`LUMO(U)` 与 `HOMO(D)` 上各变体的 `paper_avg_improvement_mean`
  - 作用：直接支撑"`wo_leaf_value` 在 `HOMO(D)` 上显著更差，`wo_prior` 仅轻微退化"

- **Panel B — Runtime fold vs full**
  - 数据源：同上
  - 展示：各变体 `avg_runtime_mean / full`
  - 作用：直观展示 `wo_leaf_value` 和 `random_topb` 的搜索成本膨胀
  - 设计：使用对数纵轴，避免 `88x` 和 `20x` 量级压扁其他柱子

- **Panel C — Expanded nodes fold vs full**
  - 数据源：同上
  - 展示：各变体 `avg_expanded_nodes_mean / full`
  - 作用：把"效率变差"从时间层面延伸到搜索规模层面，增强结论稳健性
  - 设计：同样使用对数纵轴



## 3. 为什么不把所有内容塞进一张主表

- `pilot` 是当前**唯一完整闭环的真值口径**，适合承担效果与效率的量化展示；
- `random_topb` 当前更偏"效率侧消融"，因此放在三个 panel 中保留即可。
