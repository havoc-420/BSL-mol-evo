# 主实验 BFS vs MCTS 参考数据

## 1. 数据来源

本数据提取自 `docs/paper/data/full.txt`（主实验表 5-2），用于在消融实验中提供 BFS 参考行。

**注意**：主实验表的口径与消融实验（pilot）的口径不完全一致：

| 维度 | 主实验表 5-2 | 消融 pilot |
| --- | --- | --- |
| 起始分子数 | 50 | 20 |
| 评估方式 | 真值评估 | 真值评估 |
| seed 数量 | 1（主实验默认） | 1 |
| MCTS 预算 | 400 / 800 simulations | 200 simulations（pilot） |

因此，以下数据在消融表中应标注为 **"reference"**，不宜直接与 pilot 消融数值做绝对值对比，但方向和趋势可以交叉印证。

## 4. 与消融实验的交叉对比

### 4.1 HOMO(D) 上：消融 vs 主实验 BFS

| 方法 | Avg. Improvement | 数据来源 |
| --- | ---: | --- |
| OFO-MCTS (pilot, full) | **2.0041** | 消融 pilot |
| OFO-MCTS (主实验) | **1.6361** | 主实验表 5-2 |
| OFO-BFS (主实验) | **0.9125** | 主实验表 5-2 |
| MCTS wo_leaf_value (pilot) | **0.4896** | 消融 pilot |

**关键发现**：
> **去掉 `leaf value` 后，MCTS 的 improvement（0.4896）甚至低于主实验中 BFS 的 improvement（0.9125）。**

这说明 `leaf value` 不仅让 MCTS 比"自身去掉它"更好，甚至让 MCTS 退化到了**比 BFS 还差**的水平。这是一个非常强的叙事点。

### 4.2 LUMO(U) 上：消融 vs 主实验 BFS

| 方法 | Avg. Improvement | 数据来源 |
| --- | ---: | --- |
| MCTS wo_leaf_value (pilot) | **1.2969** | 消融 pilot |
| OFO-MCTS/800 (主实验) | **1.3292** | 主实验表 5-2 |
| OFO-MCTS/400 (主实验) | **1.2847** | 主实验表 5-2 |
| OFO (BFS) (主实验) | **0.4726** | 主实验表 5-2 |
| MCTS full (pilot) | **1.1452** | 消融 pilot |

**注意**：
- LUMO(U) 上 `wo_leaf_value` 的 improvement（1.2969）居然高于 `full`（1.1452），但代价是 runtime 暴涨 20.9x
- 不过即便 `wo_leaf_value` 的 improvement 看起来还行，它仍然高于 BFS 的 0.4726
- 这说明 LUMO(U) 这个任务本身对搜索策略的区分度不如 HOMO(D)

## 5. 口径差异提醒

在论文中使用这些交叉对比时，务必注意：

1. **主实验与消融 pilot 的样本数不同**（50 vs 20），不能直接做绝对值对比
2. **MCTS 预算不同**（主实验 400/800 vs pilot 200），pilot 上的 MCTS full 可能因此低于主实验 MCTS
3. **最安全的用法**：只用方向和趋势做佐证，不用绝对值做精确对比
4. **最强的叙事点**：`wo_leaf_value` 在 HOMO(D) 上退化到比 BFS 还差——这个方向性结论不受口径差异影响，因为差距足够大

## 6. 一句话总结

> 主实验数据确认了 MCTS 整体优于 BFS，而消融数据进一步揭示：去掉 `leaf value` 后 MCTS 在 HOMO(D) 上甚至不如 BFS——这为"leaf value 是关键模块"提供了跨层级的最强证据。
