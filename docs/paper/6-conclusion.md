# 结论与展望

本文围绕分子优化中的一个核心问题展开：在离散且组合爆炸的化学编辑空间中，如何为多步优化提供可靠的局部决策信号。针对这一问题，本文提出了一条从**单步编辑响应建模**到**多步树搜索优化**的统一技术路线。与单纯关注终态分子优劣的做法不同，本文首先回答“一次局部编辑会带来什么变化”，再据此组织全局优化路径。

本文的主要工作可以概括为三个方面。第一，在建模层面，本文提出 OFO，将单步分子编辑响应建模为一个以“编辑前分子—编辑后分子—编辑操作”为输入的条件回归任务，直接预测一次局部编辑所引起的目标性质变化，并说明几何感知分子表示、双分支编码结构与编辑条件建模有助于提升这一任务的预测质量。第二，在优化层面，本文构建 OFO 引导的 `MCTS` 框架，将 OFO 的局部响应预测一致地转化为候选扩展打分、先验概率构造与叶节点价值评估信号，从而把局部建模与多步决策耦合为一个统一闭环。第三，在实验层面，本文通过主干网络比较、单步预测、多步优化、消融分析与案例研究表明：局部编辑响应不仅是可学习的，而且能够作为有效的搜索启发式，支持高质量的分子优化路径搜索。

同时，本文也暴露出若干值得进一步研究的问题。例如，单步预测误差在长路径搜索中可能逐步累积，搜索性能仍与预算规模密切相关，而更强的目标导向性也可能伴随结果多样性的下降。这些现象表明，“局部响应建模 + 树搜索”的路线虽然有效，但仍有进一步改进空间。

未来工作可以沿以下几个方向展开：一是引入不确定性估计或校准机制，使 OFO 在作为搜索启发式时同时提供置信信息；二是探索更高效的搜索策略或可学习的动作剪枝机制，以降低大分支空间下的推理开销；三是将当前单属性优化扩展到多属性联合优化，并进一步纳入更贴近真实药物发现流程的约束条件，如合成可达性、结构新颖性和 ADMET 指标。

总体而言，本文的核心结论是：**单步局部编辑响应可以被显式学习，并且这种局部响应能够进一步转化为多步分子优化中的统一搜索信号。** 这一思路为分子优化提供了更清晰的建模分层，也为后续将预测模型与搜索决策进一步耦合提供了可扩展的研究基础。
