# 引言

分子优化（molecular optimization）旨在从给定先导分子出发，通过对结构进行有目标的调整，使候选分子在保持基本化学合理性的同时，朝着期望性质方向改进。该任务在药物发现、材料设计和量子化学分子筛选中具有重要意义，因为实际研究往往并不要求“从零生成一个全新分子”，而更关注**在已有分子基础上进行受控改造**。

与静态分子性质预测相比，多步分子优化的关键难点并不只是判断“一个分子最终好不好”，而是判断“**一次局部编辑会带来什么变化，以及这一步是否值得执行**”。一方面，分子编辑空间本质上是离散且组合爆炸的：即便从一个较小分子出发，允许的加原子、换原子、调键级、构环等局部编辑组合起来，也会迅速形成庞大的搜索空间。另一方面，多步优化真正依赖的是对局部编辑响应的可靠估计；如果无法判断某一步改动究竟会使目标性质改善还是恶化，搜索过程就只能依赖粗粒度启发式规则或事后评价，从而难以在搜索效率与优化质量之间取得平衡。

已有研究大致可以分为两类。第一类方法侧重对单个分子的绝对性质进行预测，再借助外部优化器、启发式规则或生成模型进行多步改造。这类方法虽然能够刻画静态结构与性质之间的映射关系，但并未显式建模“**从一个分子编辑到另一个分子**”这一动态转移过程，因此很难直接回答某个具体编辑动作是否有利于目标性质提升。第二类方法将分子优化视为序列生成、强化学习或树搜索问题，通过策略模型、奖励函数或搜索准则来探索可能的优化路径。这类方法能够处理多步决策，但若缺乏一个针对单步编辑效果的高质量局部评价器，搜索过程仍容易面临反馈稀疏、误导扩展和组合空间过大等问题。换言之，现有路线要么更擅长做**终态评价**，要么更擅长做**搜索组织**，却较少把“局部编辑响应”作为两者之间的关键桥梁。

基于上述观察，本文采用一条分层式技术路线。首先，本文提出 OFO（One-step Feedback Optimization）基础模型，将单步分子编辑建模为一个条件响应预测任务：给定编辑前分子、编辑后分子以及对应的操作语义，直接预测该次编辑所引起的目标性质变化量。与传统静态性质预测不同，这一建模方式关注的是**局部结构变换导致的性质增量**，从而为多步优化提供更贴近决策需求的信号。其次，在单步响应模型基础上，本文进一步构建基于 OFO 与 MCTS 的分子优化框架，将 OFO 输出的局部性质变化预测嵌入树搜索过程，用于候选扩展打分、先验概率构造与叶节点价值评估，从而把“单步可学习的局部编辑响应”转化为“多步可搜索的优化路径”。

因此，本文的核心思想可以概括为：**先对局部编辑效果进行显式建模，再将该局部模型用于全局离散搜索。** 这一设计使得单步预测与多步优化形成清晰分工：前者负责提供对局部化学变换的性质响应估计，后者负责在多步编辑空间中组织探索与利用。与仅依赖静态性质预测或盲目搜索的路线相比，该框架更自然地统一了化学编辑规则、几何结构信息和目标驱动优化，也把“终态性质是否优秀”的问题进一步分解为“一步编辑是否有益”与“多步路径如何规划”两个层次。

本文的主要贡献如下：

1. **在第三章提出单步分子编辑响应预测任务。** 将编辑前后分子对与操作条件联合建模，直接学习一次离散编辑对目标性质造成的变化量，为多步优化提供局部决策信号。
2. **在第三章构建基于双分支几何编码的 OFO 模型。** 通过分别编码编辑前后分子的三维结构，并引入显式操作特征，实现对“结构变化—编辑条件—性质响应”关系的条件回归建模。
3. **在第四章提出 OFO-guided MCTS 分子优化框架。** 将 OFO 作为候选扩展的批量打分器、先验构造器和叶节点评估器，结合深度约束、可行域约束与剪枝策略，实现面向多步分子编辑的层次化搜索。
4. **在第五章从单步预测和多步优化两个层面验证方法有效性。** 通过基座筛选、预测性能比较、优化实验、消融分析和案例研究，说明该路线既能有效建模局部编辑响应，又能支持高质量的全局优化。

全文的组织结构如下。第二章回顾与本文相关的几何分子建模、分子优化与搜索式方法，并说明本文在“编辑响应建模 + 搜索式优化”交叉点上的定位。第三章介绍 OFO 单步分子编辑响应预测模型，并解释为何以性质增量作为核心建模对象。第四章进一步说明如何将 OFO 嵌入 MCTS 以执行多步分子优化。第五章给出实验设置、基线比较、消融分析、案例研究与局限讨论。最后总结全文并讨论未来工作方向。
