# 论文绘图任务清单

## 目标

围绕 `3-method-ofo.md`、`4-method-mo-mcts.md` 与 `5-experiments.md` 补齐最关键的图示，使论文能够更直观地展示：

1. 单步编辑响应预测任务是什么；
2. OFO 模型如何工作；
3. OFO 如何引导 MCTS 做多步优化；
4. 搜索路径与最终优化结果如何体现方法有效性。

## P0：必须优先完成（建议先做这 3 张）

### [ ] 图 1：OFO 单步响应预测总览图
- **用途**：作为 `3-method-ofo.md` 的主图，说明 OFO 的整体输入、编码、融合与输出。
- **建议放置位置**：`## 3. 整体架构` 附近。
- **图中应包含**：
  - 编辑前分子 `M_from`
  - 编辑后分子 `M_to`
  - 操作向量 `e`
  - 两个 `VisNet encoder`
  - 一个 `operation encoder`
  - `fusion predictor`
  - 输出 `Δy`
- **必须表达清楚的点**：
  - 这是“单步编辑响应预测”，不是绝对性质预测；
  - 模型输入是“分子对 + 操作条件”；
  - 双分支几何编码是核心设计。
- **交付标准**：
  - 有一版草图；
  - 有一版正式图；
  - 配一段图注（caption）。

### [ ] 图 2：OFO-guided MCTS 搜索流程图
- **用途**：作为 `4-method-mo-mcts.md` 的主图，说明 OFO 在 MCTS 中如何参与扩展、prior 构造、leaf value 估计与回传。
- **建议放置位置**：`## 4. MCTS 主路线` 开头。
- **图中应包含**：
  - 当前节点分子 `M_t`
  - 合法编辑枚举
  - 候选分子生成
  - OFO 批量打分 `δ`
  - Top-B 截断
  - softmax prior 构造
  - PUCT selection
  - leaf evaluation
  - backpropagation
- **必须表达清楚的点**：
  - OFO 不是后验打分器，而是搜索中的统一引导器；
  - 局部预测如何转化为全局路径选择；
  - 搜索不是盲目展开，而是先评分再扩展。
- **交付标准**：
  - 有一版流程草图；
  - 明确每个模块的箭头关系；
  - 有一段图注。

### [ ] 图 3：案例级优化路径图
- **用途**：作为 `5-experiments.md` 的关键结果图，用具体分子案例展示“局部评分如何塑造全局路径”。
- **建议放置位置**：`## 6. 案例研究与可视化`。
- **图中应包含**：
  - 起始分子
  - 中间 2–4 步关键编辑
  - 每一步的编辑动作标签
  - 每一步的 OFO 预测增量
  - 最终分子与累计收益
- **必须表达清楚的点**：
  - 路径不是随机得到的，而是受 OFO 引导；
  - 中间步骤应看得出局部变换逻辑；
  - 最终结构与性质改进之间有关联。
- **交付标准**：
  - 选定 1–2 个代表性分子案例；
  - 确定每步编辑的展示方式；
  - 输出可插入正文的图版。

## P2：配套文字与排版任务

### [ ] 为每张图写图注初稿
- **要求**：图注不要只描述“图里有什么”，还要说明“图为什么重要”。
- **建议格式**：
  - 第一句：说明图示对象；
  - 第二句：说明关键机制；
  - 第三句：说明该图服务于哪一个论文主张。

### [ ] 为正文补充“见图 X”锚点
- **建议处理位置**：
  - `3-method-ofo.md`：在介绍整体架构时引用图 1；
  - `4-method-mo-mcts.md`：在介绍搜索主路线时引用图 2；
  - `5-experiments.md`：在案例分析时引用图 3。

### [ ] 统一图形风格
- **统一项**：
  - 颜色风格（建议 2–3 个主色）
  - 分子结构高亮方式
  - 箭头粗细与线型
  - 模块框圆角与阴影
  - 数学符号写法（如 `Δy`、`δ`、`Q/N/W/P`）
- **建议**：方法图和实验图风格保持一致，避免像来自不同论文。

### [ ] 统一导出格式
- **建议优先**：`PDF` 或 `SVG`
- **备选**：`PNG`（仅在投稿系统或文档工具兼容性不足时使用）
- **检查项**：
  - 缩放后文字是否清晰；
  - 黑白打印下是否仍可区分；
  - 字号是否与正文匹配。
