# 实验设置与结果分析

## 1. 实验目标

本章从实验角度验证本文提出的“单步响应建模 + 多步树搜索优化”路线的有效性，重点回答以下三个问题：

1. OFO 是否能够稳定预测单步分子编辑带来的性质变化；
2. OFO 引导的 `MCTS` 是否能够将局部响应预测转化为有效的多步分子优化策略；
3. 几何分子编码、操作语义建模以及搜索侧的先验与剪枝机制，分别对最终性能产生了怎样的影响。

围绕上述问题，实验部分按照“基座筛选 → 单步预测 → 多步优化 → 消融分析 → 案例研究”的顺序展开，以形成从局部建模能力到全局优化行为的完整论证链条。

## 2. 主干网络比较与默认模型确定

在确定 OFO 的最终模型形式之前，本文首先在统一训练协议下比较不同分子编码主干网络对单步分子编辑响应预测任务的影响。该预实验的目的不是回顾模型开发过程，而是回答一个更适合论文叙述的问题：在相同的操作编码器与融合预测头设置下，不同分子编码主干网络对局部编辑响应建模能力有何差异。

### 2.1 比较设置

为保证比较公平，表 5-1 的主比较组（前四项）在相同的数据划分、训练流程和输出目标下进行比较，并保持以下组件一致；后四项作为补充对照，用于考察操作编码器与聚合方式变化对结果的影响：

- 分子对输入形式一致，均以编辑前分子与编辑后分子作为结构输入；
- 操作特征编码器采用相同的线性映射结构；
- 融合预测头采用相同的多层感知机；
- 评价指标统一为 `RMSE`、`MAE`、`R²`、`PCC` 与 `Rank Loss`。

其中，`RMSE` 与 `MAE` 用于衡量数值误差，`R²` 与 `PCC` 用于衡量整体拟合程度与相关性，`Rank Loss` 用于评估模型对候选编辑相对排序的保持能力。考虑到后续多步优化需要对候选动作进行排序和筛选，这些指标能够较全面地反映相应主干网络是否适合作为 OFO 的底层分子编码器。

### 2.2 结果比较

表 5-1 给出了不同模型配置在单步分子编辑响应预测任务上的结果。

| 模型名称 | RMSE | MAE | R² | PCC | Rank Loss |

| `gcn_linear_linear` | 0.4885 | 0.2568 | 0.7358 | 0.8604 | 0.4426 |
| `equiformer_linear_linear` | **0.1334** | 0.0387 | **0.9803** | **0.9906** | **0.3143** |

### 2.3 结果分析

从整体趋势看，几何感知主干网络明显优于普通二维图模型。`Equiformer`、`TorchMD-Net/TorsorNet` 和 `ViSNet` 在 `RMSE`、`R²`、`PCC` 与 `Rank Loss` 等指标上均显著领先于基于 `GCN` 的对照模型。这表明，对于单步编辑响应预测任务，仅依赖拓扑邻接关系并不足以充分描述局部结构变化对性质的影响，而显式利用三维几何信息能够带来更强的建模能力。

进一步比较可知，`equiformer_linear_linear` 在 `RMSE`、`R²`、`PCC` 和 `Rank Loss` 上取得最优结果，说明其在整体拟合精度、相关性保持以及候选编辑排序方面具有明显优势。与此同时，`visnet_linear_linear` 虽然在全局拟合指标上略逊于 `Equiformer`，但在 `MAE` 上取得最低值，反映出 `ViSNet` 在控制局部绝对误差方面具有突出表现。对于后续 OFO 引导的 `MCTS` 而言，这一点尤为重要，因为树搜索更依赖对单步候选编辑的局部评分可靠性，而不仅仅是整体回归拟合程度。

综合上述结果，本文最终采用 `ViSNet` 作为 OFO 的默认分子编码主干。其原因在于，`ViSNet` 在保持整体竞争性能的同时，对单步局部误差的控制更强，更适合作为多步搜索中的局部打分器。

## 3. 单步分子编辑响应预测实验

### 3.1 数据集与任务设置

本节的核心问题是：**局部编辑响应是否可学，以及这种可学习性是否足以支撑后续搜索阶段的局部启发式构造。** 因此，单步预测实验以编辑前后分子对为基本样本单元。对于每个样本，模型输入包括编辑前分子、编辑后分子以及与该次编辑对应的操作描述符，输出为该步编辑引起的目标性质变化量。与传统静态性质预测不同，该任务直接面向“局部结构变换导致的性质增量”建模，更贴近后续多步优化中的决策需求。

在实验协议上，数据划分采用分子级别划分，以避免同一分子或高度相似的编辑样本同时出现在训练集与测试集中，从而更真实地评估模型对未见编辑样本的泛化能力。对于接近零的性质，采用绝对差值作为监督信号；对于其余性质，则采用相对变化形式进行建模，以提高不同量纲样本之间的可比性。

### 3.2 评价指标

单步预测部分采用如下五项指标进行评估：

- `RMSE`：衡量整体误差规模；
- `MAE`：衡量局部绝对误差，对后续候选打分的稳定性尤为关键；
- `R²`：衡量模型对目标变化的解释程度；
- `PCC`：衡量预测值与真实值之间的线性相关性；
- `Rank Loss`：衡量模型对候选编辑相对排序的保持能力。

其中，`Rank Loss` 对本文任务尤为重要，因为树搜索更关心候选动作的相对优先级，而不仅仅是单点预测误差。换言之，一个适合用于 `MCTS` 的单步预测器，不仅需要回归数值准确，还需要能够稳定地区分“更优编辑”和“更差编辑”。

### 3.3 实验关注点

单步预测实验重点考察三个方面：第一，几何感知主干网络是否能够稳定提升对编辑响应的建模能力；第二，显式操作条件是否有助于区分不同局部编辑的性质效应；第三，模型在 `MAE` 与 `Rank Loss` 上的表现是否足以支撑后续搜索阶段的候选排序与分支筛选。若实验结果在这些维度上同时成立，则说明 OFO 具备作为局部评价器的基础条件。

## 4. 多步分子优化实验

### 4.1 任务与对比设置

多步优化实验以给定起始分子为输入，在离散化学编辑空间中执行受约束搜索，目标是在有限编辑步数内使目标性质朝指定方向变化。根据已经整理完成的实验结果，本文优先报告四组任务：`LUMO(D)`、`LUMO(U)`、`HOMO(D)` 与 `HOMO(U)`，其中 `D` 与 `U` 分别表示使目标性质减小与增大。每组任务均以 `50` 个起始分子作为输入，并统计优化后候选分子的性质改进、成功率、结构多样性与相似性等指标。

在对比方法上，主结果部分采用 `DST`、`FFLOM`、`DyMol`、`CMOMO`、`TransDLM` 作为外部基线，并与本文方法 `OFO` 及其搜索版本进行比较。鉴于当前 `GAP` 任务尚未补齐完整统计量，本文主结果主要报告 `LUMO` 与 `HOMO` 两类任务，并在此基础上分析不同方法在目标导向优化、多样性保持与结构相似性之间的权衡关系。

### 4.2 评价指标与结果整理方式

多步优化实验采用“核心优化指标 + 辅助结构指标”的结果组织方式。核心指标包括：

- **优化收益**：终态分子相对起始分子的平均改善值；
- **成功率**：达到目标方向或满足阈值要求的样本比例；
- **结构多样性**：以 `IntDiv` 为代表，反映候选结果是否过于集中；
- **结构保持**：以 `Morgan` 相似度或 `GED` 相似度反映与源分子的接近程度。

此外，`QED`、`logP`、环数和 `HAMDIV` 等指标用于辅助分析优化结果的可行性、多样性与结构保持，而 `平均改善值`、`改善百分比` 与 `总排名` 则更直接反映方法的整体优化能力。

表 5-2 统一汇总了 `LUMO(D)`、`LUMO(U)`、`HOMO(D)` 与 `HOMO(U)` 四组任务的结果，使不同方法在优化能力、成功率、多样性与结构保持之间的权衡能够在同一视图下进行比较。

基于表 5-2，结果分析主要围绕“**按任务分组读取结果，并按核心指标归纳结论**”展开。本文首先关注 `平均改善值` 与 `改善百分比`，判断方法是否真正实现目标导向优化；其次结合 `总排名` 观察方法在多指标综合评价下的整体位置；最后再参考 `QED`、`logP`、`IntDiv`、`Morgan` 相似度与 `GED` 相似度，分析优化结果在成药性、结构多样性与结构保持上的代价与收益。

### 4.3 结果分析

为更直接回应本文的核心论点，本节从两个层次解读表 5-2：首先比较本文方法与外部基线的相对位置，以回答“这一路线是否有效”；其次比较 `OFO` 系列内部不同搜索策略的差异，以回答“单步响应模型”与“单步响应模型 + 树搜索”之间是否存在实质差别。

#### 4.3.1 与外部基线的比较

从 `LUMO(D)` 分组可以看出，`OFO` 在 `平均改善值`、`改善百分比` 与 `总排名` 上均取得最佳结果，说明本文基于局部编辑响应的路线在目标性质下降任务上具有较强竞争力。这表明：即使不显式引入复杂搜索，单步响应模型本身也已经能够为目标方向较明确的任务提供高质量候选排序。

在 `LUMO(U)` 分组中，`DyMol` 在平均改善值、改善百分比和总排名上仍然占优，说明外部方法在该类“向上优化”任务上具有较强竞争力；但从本文方法的表现看，局部响应建模并未失效，而是需要更强的路径级搜索组织。类似地，在 `HOMO(D)` 与 `HOMO(U)` 两组任务中，`CMOMO` 展现出较强的综合优势，说明多目标进化式策略在这些任务上仍具有重要参考价值。总体而言，外部基线比较说明本文方法并非在所有任务上一致占优，但它已经在若干关键任务上证明：**以局部编辑响应为核心的路线具备真实的全局优化能力，而不是只在单步预测层面有效。**

#### 4.3.2 `OFO` 家族内部比较

若进一步只看 `OFO` 系列内部结果，树搜索的贡献会更清晰地显现出来。在 `LUMO(D)` 中，`OFO` 与 `OFO-mcts` 的平均改善值接近，而 `OFO` 的综合排名甚至略高，这说明在目标方向明确、局部评分足够稳定时，单步响应模型本身已经能够提供较强的优化指导能力，额外引入树搜索未必带来显著增益。

但在更困难的 `LUMO(U)` 任务中，`OFO` 到 `OFO-mcts/400` 与 `OFO-mcts/800` 的变化则更具代表性：单独使用 `OFO` 时，平均改善值仅为 `0.4726`，成功率为 `64.40%`；而引入 `MCTS` 后，这两项指标分别提升到 `1.2847`/`1.3292` 和 `83%` 左右。也就是说，`OFO` 负责回答“哪一步编辑更可能有益”，而 `MCTS` 进一步回答“如何把若干局部有益编辑组织成更优路径”。

同样地，在 `HOMO(D)` 与 `HOMO(U)` 任务中，`OFO-MCTS-Dec` / `OFO-MCTS-Inc` 相比各自的 `BFS` 版本均取得更高的改善值或成功率。这说明在固定局部评分器的前提下，搜索策略本身仍会显著影响最终结果；换言之，本文的收益并不只来自更好的单步预测器，也来自把该预测器转化为层次化搜索信号的方式。

综合表 5-2，可得出三个较为清晰的结论。第一，`OFO` 系列方法在 `LUMO(D)` 这类目标方向明确的任务上表现突出，说明单步编辑响应预测本身已具备较强的优化指导能力。第二，在 `LUMO(U)` 与 `HOMO` 等更复杂任务上，`MCTS` 能够进一步放大 OFO 的局部评分优势，使其在成功率和综合排名上获得更稳定的提升。第三，本文方法在若干任务上仍呈现出多样性下降、结构探索范围收缩的现象，这意味着“局部响应建模 + 树搜索”虽然有效，但其收益伴随着探索与利用权衡的真实代价。

### 4.4 `MCTS` 超参数敏感性与默认配置

为评估搜索侧超参数对 OFO 引导的 `MCTS` 的影响，本文在 `LUMO(D)` 任务上固定其余设置，对搜索预算、探索系数、搜索深度与剪枝耐心值进行单因素扫描，其趋势见图 `3.5`；详细结果见相应的超参数敏感性统计表。

| 超参数 | 代表性观察 | 实验含义 |
| --- | --- | --- |
| `num_simulations` | 从 `100` 增加到 `1600` 时，`average_improvement` 由 `-3.4154` 提升到 `-3.8891`，同时 `IntDiv` 由 `0.4707` 下降到 `0.3942` | 更高搜索预算能够持续释放优化潜力，但收益呈现边际递减，并伴随多样性收缩 |
| `exploration_weight` | 从 `0.5` 增加到 `3.0` 时，`average_improvement` 由 `-3.4008` 提升到 `-4.1264`，成功率由 `89.88%` 升到 `93.28%`，`IntDiv` 由 `0.4416` 降到 `0.2976` | 探索系数直接控制性能—多样性权衡，是 `MCTS` 搜索行为中最关键的控制参数之一 |
| `max_depth` | 从 `2` 增加到 `12` 时，`average_improvement` 近似单调提升（`-2.1164 → -3.5769`），而 `Morgan` 相似度由 `0.2190` 下降到 `0.0875` | 更深编辑路径对释放多步优化潜力是必要的，但也会带来更强结构偏移；`10–12` 已接近收益饱和区间 |
| `pruning_patience` | 从 `1` 到 `4` 的变化整体较温和 | 剪枝耐心值会影响局部搜索风格，但不是决定性性能来源，更适合作为稳定性参数 |

上述结果表明，`MCTS` 侧各超参数对最终优化行为的影响并不相同。首先，`num_simulations` 直接决定搜索预算上限；当其由 `100` 增至 `1600` 时，平均改善值持续提升而 `IntDiv` 同步下降，说明更高预算能够持续释放优化潜力，但其收益并非线性增长，而是伴随着多样性收缩。其次，`exploration_weight` 对性能—多样性平衡的影响最为直接。随着探索系数增大，平均改善值与成功率同步上升，而 `IntDiv` 持续下降，表明更强探索有助于搜索跳出局部最优并发现更有效的编辑路径，但也会推动结果向更激进、偏离起始结构更远的区域收缩。再次，`max_depth` 的提升几乎单调改善优化结果，并同步降低 `Morgan` 相似度，说明多步编辑路径本身是获得更强性质改善的必要条件；与此同时，`10` 到 `12` 的性能增益已明显放缓，表明当前任务下搜索深度已接近收益饱和区间。

相比之下，`pruning_patience` 的影响整体较为温和，更适合作为控制局部搜索风格与稳定性的辅助参数，而非决定性性能来源。类似地，`max_branching` 的结果虽然支持“高质量候选排序足以支撑有限宽度搜索”这一判断，但其主要作用在于补充说明搜索效率机制，而非解释优化性能的核心来源。

基于上述结果，本文在 `LUMO(D)` 任务上采用 `num_simulations = 800`、`exploration_weight = 2.0`、`max_depth = 10` 与 `pruning_patience = 3` 作为较为平衡的默认设置；其中 `max_branching = 10` 保留为实现层面的默认值。总体而言，这组敏感性分析进一步表明，`OFO` 提供的局部响应信号能够被 `MCTS` 在预算、探索与深度三个维度上稳定利用，而并非只在某一组偶然参数下才成立。

## 5. 消融实验

为了进一步分析各个模块的实际贡献，本文分别从 OFO 侧与 `MCTS` 侧进行消融。

### 5.1 OFO 侧消融

OFO 侧消融主要考察以下变体：

- 去掉操作特征，仅保留分子对输入；
- 去掉三维几何信息，仅保留二维图结构；
- 用单分支差分表示替代双分支编码。

该组消融用于验证显式编辑条件是否必要、几何主干网络是否确实贡献了预测能力，以及双分支结构是否更适合建模性质增量而非静态性质值。

### 5.2 `MCTS` 侧消融：`BFS` 与 `MCTS` 搜索策略对比

`MCTS` 侧消融的核心对比是在**保持 OFO 评分器、约束条件与候选动作集合一致**的前提下，仅替换搜索策略，将 `OFO-BFS` 与 `OFO-MCTS` 进行比较。由于这一对比只改变树搜索机制本身，而不改变局部性质预测器，因此能够更直接地刻画搜索模块对最终优化结果的贡献。

本文直接利用表 5-2 中 `HOMO(D)` 与 `HOMO(U)` 两个任务分组内的 `OFO-BFS` / `OFO-MCTS` 对应结果进行分析，从而在统一结果表中比较不同搜索策略的差异。

具体来看，在 `HOMO(D)` 任务中，`OFO-MCTS-Dec` 的平均改善值由 `OFO-BFS-Dec` 的 `-0.9125` 提升至 `-1.6361`，成功率也由 `72.06%` 提高到 `88.74%`，并在总排名上进入该任务并列第 `1`。这说明对于下降型目标，`MCTS` 能够更有效地把搜索预算分配到高价值分支上，从而把 OFO 的局部评分优势转化为更强的全局优化结果。

在 `HOMO(U)` 任务中，`OFO-MCTS-Inc` 与 `OFO-BFS-Inc` 的平均改善值差异较小，但成功率由 `81.27%` 明显提升到 `95.05%`。与此同时，`MCTS` 版本的 `IntDiv` 和优化后分子数均低于 `BFS`，表明其代价是探索范围收缩、结果分布更加集中。换言之，`MCTS` 带来的收益主要体现为**更强的目标导向性**，而代价则是**一定程度的多样性损失**。

因此，从 `HOMO` 分组的结果可以得到本文在搜索模块上的核心结论：**OFO 提供了可学习的局部响应信号，而 `MCTS` 进一步提升了该信号在多步决策中的利用效率；但这种提升并非没有代价，而是伴随着探索范围收缩与多样性下降。** 在此基础上，更细粒度的消融——例如去除 OFO 先验、叶节点价值或剪枝约束——可进一步揭示各搜索组件的独立贡献，留作后续工作。

## 6. 案例研究与可视化

除总体统计结果外，本文还通过案例分析展示 OFO 引导的 `MCTS` 如何在具体分子上形成优化路径。与仅给出“起点—终点”对照不同，案例研究围绕完整的路径证据链展开，重点展示以下内容：

- 起始分子、终态分子及其关键结构差异；
- 每一步编辑动作的具体含义与对应结构变化；
- OFO 对各步性质增量的预测变化，以及必要时与真实变化的对照；
- `MCTS` 对不同候选分支的保留与舍弃依据；
- 最终路径在目标性质、结构保持和多样性上的收益与代价。

通过对 `1` 到 `2` 个代表性样本的路径展开分析，并结合路径图、分子结构图或分步表格，案例研究不仅提供了直观示例，也进一步说明局部评分并非停留在表格层面，而是会切实影响搜索树中的扩展、选择与路径收敛过程。

## 7. 讨论与局限

结合前述结果，可以进一步看到本文路线的边界。首先，OFO 的单步预测误差在长路径搜索中仍可能逐步累积，因此即便局部评分总体有效，随着搜索深度增加，叶节点价值估计仍可能出现偏移。其次，`MCTS` 的收益与搜索预算密切相关：在 `LUMO(U)`、`HOMO(D)` 等更困难任务中，更多预算确实能够提升成功率与平均改善值，但也会带来更高的推理成本。再次，从 `BFS` 与 `MCTS` 的比较可以看出，更强的目标导向性往往伴随着探索范围收缩和结果多样性下降，这意味着方法仍需在探索与利用之间做更细致的权衡。

此外，当前实验中的约束机制主要由深度限制、`logP` 可行域约束与若干剪枝规则构成，它们能够有效控制搜索空间，但本质上仍属于启发式近似，并不等价于真实药化设计中的复杂约束体系。因此，后续若要提升方法的应用价值，还需要把更多与合成可达性、ADMET 或多目标权衡相关的真实约束纳入统一框架。

## 8. 本章小结

本章从主干网络比较、单步预测、多步优化、消融分析、案例研究与讨论六个方面对全文方法进行了验证。现有结果表明，几何感知分子编码对于单步编辑响应预测是必要的，而较低的 `MAE` 与更稳定的候选排序能力使 OFO 更适合作为多步搜索中的局部评分器。多步优化与消融分析进一步说明：本文的收益不仅来自单步响应的可学习性，也来自将该局部响应一致地转化为 `MCTS` 中的扩展、先验与价值信号；与此同时，搜索预算、误差累积与多样性损失仍是后续需要继续处理的重要问题。
