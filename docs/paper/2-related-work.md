# 相关工作

本文的研究与三条工作脉络密切相关：几何感知的分子表示学习、面向性质改进的分子优化与分子编辑方法，以及搜索式分子优化尤其是 `MCTS` 路线。下面分别进行回顾，并据此说明本文的研究定位。

## 1. 几何感知的分子表示学习

分子性质预测长期依赖基于二维拓扑图的 `GCN`、`GAT`、`MPNN` 等模型，但对于量子化学性质、构象变化或局部扰动敏感的任务而言，仅依赖键连接关系往往不足以刻画真实化学环境。为此，越来越多工作开始显式引入三维几何信息。

代表性方法如 `Equiformer`、`TorchMD-Net` 和 `ViSNet`，分别从等变 Transformer、等变消息传递以及向量—标量交互等角度建模原子坐标、相对位移和局部空间关系。其中，`Equiformer` 表明 Transformer 架构同样能够有效适配三维原子图；`ViSNet` 则进一步强调局部几何编码的精细性与计算效率。这些工作共同说明，三维结构对于精细性质建模具有重要价值。对本文而言，若要预测一次局部编辑带来的性质变化，不仅要知道“哪些原子发生了变化”，还需要刻画“这些变化发生在怎样的几何环境中”。因此，几何感知表示学习不仅是分子性质预测的基础能力，也是支撑局部编辑响应建模的重要前提。

## 2. 分子优化与分子编辑方法

与从零生成分子不同，分子优化更强调从已有分子出发，在尽量保留骨架或药效团的基础上实现性质改进。现有方法大致可分为规则驱动、强化学习、条件生成和搜索优化等几类。规则或枚举方法具有较强可解释性，但在大搜索空间下效率有限；强化学习能够处理序列决策，但常受奖励稀疏和训练不稳定影响；条件生成方法表达能力较强，但在结构保持和局部可控性方面仍存在不足。

从代表工作看，`TransDLM` 体现了文本引导的条件生成或编辑思路，`DST` 代表了可微结构优化路线，`CMOMO` 则体现了受约束多目标优化框架。它们分别从生成、连续优化和 Pareto 搜索等角度提升了分子优化能力，但大多仍以“获得更优终态分子”为直接目标，即更关注**终态评价**而非**转移级评价**。换言之，这些方法通常更擅长回答“哪个分子更好”，却较少显式回答“某一次局部编辑会带来怎样的性质变化”。相比之下，本文将“编辑前分子—编辑后分子—编辑动作”作为统一建模对象，把单步编辑响应作为多步优化中的局部评价信号，从而把优化粒度从分子级终态评价进一步推进到编辑级转移评价。

## 3. 搜索式分子优化与 `MCTS`

在离散编辑空间中，搜索方法天然适合处理多步决策问题，其中 `MCTS` 能够在探索与利用之间取得较好平衡，因此被广泛用于组合优化与分子设计。其优势在于：节点可对应中间分子状态，边可对应编辑动作，并可借助先验概率、价值函数和剪枝规则控制搜索复杂度；但与此同时，其效果也高度依赖局部启发式信号的质量。

已有搜索式方法通常依赖规则枚举、手工打分函数、外部性质预测器或单独训练的全局价值网络来评估中间状态。这些路线能够组织搜索过程，却未必能稳定刻画“当前这一步编辑是否值得执行”。本文与传统搜索式分子优化工作的区别在于：本文并不依赖单独训练的全局价值网络，也不将 `MCTS` 仅作为规则枚举后的后处理器，而是直接利用 OFO 学到的**单步性质变化预测**来构造候选打分、先验概率与叶节点价值，使搜索过程与局部编辑响应预测直接耦合。

## 4. 本文定位

综合来看，本文位于三条研究脉络的交叉点：

- 在**分子表示学习**方面，本文采用几何感知分子编码，强调三维局部环境对编辑响应建模的重要性；
- 在**分子优化任务**方面，本文不直接从零生成终态分子，而是聚焦于可解释的单步局部编辑；
- 在**搜索方法**方面，本文将学习得到的单步响应模型嵌入 `MCTS`，以连接局部预测与全局优化。

因此，本文的贡献不在于提出一个孤立的新型主干网络，也不在于单独实现某一种既有搜索策略，而在于提供一种统一框架：**先学习单步编辑响应，再用该响应信号驱动多步分子优化。** 从这一意义上说，本文位于“编辑响应建模”与“搜索式分子优化”的交叉点，其关注重点并非单纯获得更优终态分子，而是为多步优化提供一种可靠、可学习且能够嵌入搜索过程的局部决策信号。
