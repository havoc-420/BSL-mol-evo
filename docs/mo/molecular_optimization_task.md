# 分子优化任务目标与思路

## 任务目标

基于已训练的分子属性预测模型，实现一个分子优化系统，该系统能够：

1. 以任意起始分子 A 为基础
2. 通过树形搜索自动生成可能的目标分子或从候选列表中选择目标分子
3. 预测分子 A 经过若干步操作演化到目标分子的属性变化
4. 根据用户指定的属性变化方向（上升/下降）筛选出满足条件的分子

## 核心思路

### 1. 模型基础

使用基于 step=1 数据集训练的模型作为基础预测器：

- 模型路径: `/home/rhj/projects/mol_opt/mol-ofo/mol_evo/output/v0/visnet_linear_linear/train-20251022_072726-mu_change-30000-500`
- 目标属性: mu_change (偶极矩变化)
- 模型架构: VisNet + Linear + Linear

### 2. 多步演化处理策略

由于模型是基于单步演化(step=1)训练的，对于多步演化任务(step>1)需要采用迭代预测方法：

```
对于 step=2 的任务:
A --(step1)--> A1 --(step2)--> B
需要分别预测:
1. A -> A1 的属性变化
2. A1 -> B 的属性变化
3. 累计总变化 = 变化1 + 变化2
```

### 3. 分子生成与筛选机制

根据用户需求采用不同的策略生成和筛选分子：

1. 候选分子列表模式：

   - 从用户提供的候选分子列表中筛选满足条件的分子
   - 属性上升需求: 筛选预测变化值 > 0 的分子
   - 属性下降需求: 筛选预测变化值 < 0 的分子

2. 树形搜索模式：
   - 以起始分子为根节点，构建演化树
   - 每个节点代表一个分子状态
   - 边代表可应用的化学操作（添加原子、形成键、成环等）
   - 使用束搜索（beam search）控制搜索宽度
   - 累计从起始分子到当前节点的总属性变化
   - 筛选出满足属性变化方向要求的分子

## 技术实现要点

### 1. 模型加载与预测

- 加载训练好的 VisNet 模型
- 实现单步演化属性变化预测功能
- 支持模型标准化/反标准化处理

### 2. 化学操作生成

- 支持多种化学操作类型：
  - 原子级操作：添加、替换、删除原子
  - 键级操作：形成单键、双键、三键
  - 环级操作：在适当原子对之间形成环或芳香环
- 基于当前分子结构智能推断可能的操作
- 确保生成的化学操作具有化学合理性

### 3. 分子演化树构建

- 以起始分子为根节点构建演化树
- 每个节点包含分子状态和累计属性变化值
- 使用树形结构表示分子演化路径
- 支持追踪从起始分子到任意节点的完整演化路径

### 4. 束搜索策略

- 为避免组合爆炸，采用束搜索（beam search）策略
- 每层扩展所有可能操作后，仅保留属性预测最优的前 k 个节点继续搜索
- 束宽度（beam width）作为可配置参数
- 平衡搜索广度与计算开销

### 5. 多步演化预测

- 实现迭代预测算法处理多步演化
- 累加各步预测结果得到总变化值
- 支持任意深度的演化路径预测

### 6. 分子筛选与排序

- 根据预测变化值筛选满足条件的分子
- 支持按变化幅度排序展示结果
- 提供多种筛选模式（基于候选列表或树形搜索）

## 使用流程

### 基于候选分子列表的优化：

```bash
python mol_evo/molecule_optimizer.py \
  --model-path <模型文件路径> \
  --model-dir <模型目录路径> \
  --start-smiles <起始分子SMILES> \
  --candidate-file <候选分子CSV文件> \
  --direction {increase|decrease} \
  --max-steps <最大演化步数>
```

### 基于树形搜索的优化：

```bash
python mol_evo/molecule_optimizer.py \
  --model-path <模型文件路径> \
  --model-dir <模型目录路径> \
  --start-smiles <起始分子SMILES> \
  --search-mode tree \
  --max-depth <最大搜索深度> \
  --beam-width <束宽度> \
  --direction {increase|decrease}
```

## 输出结果

脚本将输出满足条件的分子列表，包括：

- 分子 SMILES
- 预测的属性变化值
- 演化深度（树形搜索模式）
- 演化路径（树形搜索模式）

结果将同时保存到 CSV 文件中，便于后续分析和使用。
